# Title: Focal Loss for Imbalanced Customer Churn Prediction
# Experiment description: Replace the standard cross-entropy loss with focal loss to address class imbalance (27% churn vs 73% non-churn). Focal loss down-weights easy examples and focuses training on hard-to-classify samples. Implement focal loss with tunable gamma parameter, compare gamma=0, 0.5, 1.0, 2.0, 3.0 against baseline cross-entropy and weighted cross-entropy. Evaluate using accuracy, precision, recall, F1-score, and AUC-ROC on the test set.
