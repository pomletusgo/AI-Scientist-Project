# Title: Focal Loss for Imbalanced Customer Churn Prediction
# Experiment description: Replace the standard cross-entropy loss with focal loss to address class imbalance (27% churn vs 73% non-churn). Focal loss down-weights easy examples and focuses training on hard-to-classify samples. Implement focal loss with tunable gamma parameter, compare gamma=0, 0.5, 1.0, 2.0, 3.0 against baseline cross-entropy and weighted cross-entropy. Evaluate using accuracy, precision, recall, F1-score, and AUC-ROC on the test set.

## Plot descriptions

- `best_val_loss.png` : Bar chart comparing the best validation loss (lower is better) across all configurations: Baseline, Weighted CE, Focal (γ=0.5), Focal (γ=1.0), Focal (γ=2.0), and Focal (γ=3.0). This chart highlights the dramatic loss reduction achieved by the focal loss family compared to standard cross-entropy.

- `accuracy.png` : Bar chart of test‑set accuracy. While accuracy is a straightforward metric, it can be misleading under high class imbalance (73% non‑churn vs 27% churn). This chart provides a reference for overall correctness but should be interpreted together with the other metrics.

- `precision.png` : Bar chart of test‑set precision for the churn (positive) class. High precision means that when the model predicts churn, it is likely correct, i.e., few non‑churn customers are misclassified as churners.

- `recall.png` : Bar chart of test‑set recall for the churn (positive) class. High recall indicates the model captures a large fraction of the actual churners, which is often the more important goal in churn prediction scenarios.

- `f1_score.png` : Bar chart of the test‑set F1 score, the harmonic mean of precision and recall. This single metric balances the precision‑recall trade‑off and is especially informative for imbalanced classification problems.

- `auc_roc.png` : Bar chart of the Area Under the Receiver Operating Characteristic curve (AUC‑ROC). AUC‑ROC is a threshold‑independent measure of how well the model separates churn from non‑churn customers; higher values denote better discrimination.
