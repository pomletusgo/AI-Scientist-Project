# Title: Causal-Masked Neural Networks for Counterfactual Glucose Trajectory Simulation in Diabetes
# Experiment description: Introduce a SparseCausalLinear layer that replaces the first nn.Linear in the MLP. It uses a predefined binary mask that respects a causal DAG ordering (e.g., root variables feed into all, treatments only feed into outcomes). During inference, an intervention mode sets a feature node to a chosen value and zeroes its incoming parent connections, then propagates through the network to predict the outcome. Training is conducted jointly on all endogenous variables, but a reconstruction loss can be added. To evaluate, generate synthetic tabular data from a known causal model (linear/nonlinear) with known intervention effects. Compare the Causal-Masked MLP against a standard MLP and a linear SCM on: (1) mean absolute error of predicted intervention effects vs. ground truth, (2) standard prediction accuracy. Metrics include ATE bias, counterfactual error, and R². All modifications are contained in a new model class and an intervention module; the existing data loading, evaluation, and plotting code can be reused. The synthetic data generation will be implemented as a separate utility within the script.

## Plots

The `plot.py` script generates the following figures (saved under the `plots/` directory):

- **best_val_loss.png**: Bar chart comparing the best validation loss across all runs. Lower values indicate better predictive performance on the held-out validation set. This metric is reported for every run and captures overall fitting quality independent of causal objectives.

- **r2_score.png**: Bar chart showing the R² score on the test set for runs evaluated on synthetic data (runs 2–5). R² measures how well the predicted outcomes match the true outcomes; higher values indicate better standard prediction accuracy. For runs that did not produce an R² value (e.g., the baseline runs on default CSV data) this bar is absent.

- **ate_bias.png**: Bar chart of the absolute bias of the predicted average treatment effect (|pred_ATE – true_ATE|) for the synthetic runs. A lower value indicates that the intervention effect estimated from the model’s counterfactual predictions is closer to the true causal effect. This directly evaluates the causal estimation capability of each model.

- **mae_do1.png**: Bar chart of the mean absolute error between the model’s predicted outcomes under intervention do(T=1) and the ground-truth counterfactual outcomes for the same test points. This metric isolates the performance of each model for a specific intervention, complementing the ATE bias.

Together these figures support the comparisons described in the experiment: standard MLP vs. causal‑masked MLP vs. linear SCM, on linear and nonlinear data.
