# Title: Actionable Counterfactuals from Informed Predictive Models: Training MLPs with Curvature Regularization for Stable Gradient-Based Inversion
# Experiment description: Modify the training loop in the provided script: after computing the task loss (e.g., CrossEntropy), use torch.autograd.grad to obtain the gradient of the loss w.r.t. the input batch, compute its squared L2 norm, and add it as a regularization term (weighted by a coefficient lambda) to the total loss. This encourages a locally linear decision surface amenable to inversion. After training, implement a counterfactual generation function that, given a sample and a desired target class (or a target value for regression), iteratively perturbs the input using gradient descent (Adam or L‑BFGS) to minimize a loss combining negative log-likelihood of the target plus an L2 distance penalty; early‑stop once the prediction changes. Evaluate both a standard MLP and the curvature‑regularized model on (1) standard predictive metrics (accuracy/R²), (2) counterfactual validity (percentage of test samples successfully flipped), (3) proximity (mean L2 distance of minimal perturbation), and (4) sparsity (average number of altered features). Include a random perturbation baseline. Results are produced within the existing output structure and saved to the same metrics files for comparison.

# Figures and Their Descriptions

## comparison_all.png
This figure, generated by `plot.py`, is a multi‑panel bar chart that compares the eight key metrics across all runs:
- **best_val_loss_mean** – Lowest validation loss achieved during training.
- **final_train_loss_mean** – Training loss after the last epoch.
- **cf_validity_mean** – Fraction of test samples for which the gradient‑based counterfactual search found a successful perturbation (always 1.0 in our experiments).
- **cf_proximity_mean** – Average L2 distance of the closest successful counterfactual perturbation (lower is better).
- **cf_sparsity_mean** – Average number of features changed in the closest successful counterfactual.
- **random_validity_mean** – Fraction of test samples for which random Gaussian noise produced a flipped prediction.
- **random_proximity_mean** – Average L2 distance of random perturbations that succeeded.
- **random_sparsity_mean** – Average number of features changed by successful random perturbations.

The runs are labelled:
- **run_0** – Baseline (no counterfactual evaluation).
- **run_1** – Standard MLP (no curvature regularisation) + counterfactual evaluation.
- **run_2** – Curvature‑regularised MLP with λ = 0.1.
- **run_3** – Curvature‑regularised MLP with λ = 0.01.

Each metric appears in its own subplot, enabling direct visual comparison across training strategies. This single plot is the primary figure for the paper.

## Individual Run Plots
Inside each `run_X/` directory, the training script saves two additional figures:
- **loss_curve.png** – Training and validation loss curves over epochs for that run.
- **accuracy_curve.png** – (Classification tasks only) Training and validation accuracy curves over epochs for that run.

These plots help verify convergence and the impact of the curvature regularisation on training dynamics.
