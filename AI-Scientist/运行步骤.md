## 第四步：选择运行模式

### 模式 1：评审一篇已有的 PDF 论文（最快，~2分钟）

```bash
python run_llm_pipeline.py \
  --task review \
  --paper ai_scientist/fewshot_examples/attention.pdf \
  --model deepseek-v4-pro
```

**做什么**：AI 读取 PDF 论文，输出 NeurIPS 标准评审（打分 + 优缺点 + Accept/Reject）

**输出文件**：在被评审 PDF 同目录下生成 `*_review.json`

**换成你自己的论文**：把 `--paper` 后面改成你的 PDF 路径

---

### 模式 2：生成研究想法（~1分钟）

```bash
python run_llm_pipeline.py \
  --task ideation \
  --experiment nanoGPT \
  --model deepseek-v4-flash \
  --num-ideas 5
```

**做什么**：基于 NanoGPT 模板，让 AI 生成 5 个研究想法

**模板选择**：`nanoGPT` / `2d_diffusion` / `grokking`

**输出文件**：`templates/nanoGPT/ideas.json`

---

### 模式 3：生成完整论文（~5分钟）

```bash
python generate_paper.py
```

**做什么**：一键跑通全流程：
1. 生成研究想法
2. 创建模拟实验数据
3. 逐节撰写论文（Abstract → 结论）
4. 自动评审论文

**输出文件**：
- `results/generated_paper.md` —— 完整论文
- `results/generated_paper_idea.json` —— 想法和实验数据
- `results/generated_paper_review.json` —— 评审结果

---

### 模式 4：完整流水线（想法 → 模拟实验 → 写论文，~3分钟）

```bash
python run_llm_pipeline.py \
  --task pipeline \
  --experiment nanoGPT \
  --model deepseek-v4-pro \
  --num-ideas 2
```

## 可能遇到的问题

| 问题 | 解决 |
|------|------|
| `KeyError: DEEPSEEK_API_KEY` | 没设置 API Key，执行第二步 |
| `No module named ai_scientist` | 没在项目目录，执行第三步 |
| 网络超时 | API 调用失败，等待几秒重试 |
| 中文乱码 | Git Bash 编码问题，不影响结果文件 |
